搜索 QQ Docs？

这里的 QQ Docs、QQDocs 和 docs.qq.com 指的是同一个腾讯文档（Tencent Docs）服务。本社区 Codex 插件直连腾讯官方 MCP 服务，用于查找、读取和编辑您的文档与表格。

让 Codex 帮您安装

复制以下提示词并粘贴到 Codex。不要在聊天中提供令牌。

Codex
请安装 https://github.com/akashmahedy/Tencent-Docs-Plugin-for-AI-Agent。按 START_HERE_FOR_CODEX.md 操作。不要假设电脑已安装 Node.js。同时支持 Windows 和 macOS。请先识别我的操作系统，再使用对应启动器：Windows PowerShell 运行 .\setup.cmd；macOS 终端运行 bash setup.command（也支持 Linux）。两个启动器都会在缺少 Node.js 或版本过旧时自动下载并校验。在 Node 就绪前不要直接运行 node setup.mjs。在交互式终端让我私下输入腾讯令牌。

Windows 与 Mac 三步安装

01

下载并解压

同一个 ZIP 同时支持 Windows 和 Mac。下载最新发布包并完整解压。需要支持插件的 Codex；需要时会自动准备 Node.js。

02

运行中文向导

Windows 双击 setup.cmd；macOS 打开 setup.command。向导自动准备 Node.js、安装插件并检查连接。

03

配置个人令牌

从腾讯页面获取自己的令牌，在隐藏终端输入中粘贴。成功后重启 Codex 并新建聊天。

腾讯令牌页面 ↗
Windows PowerShell
.\setup.cmd --lang=zh
Mac 终端 / Linux
bash setup.command --lang=zh

不要把令牌粘贴到聊天或 GitHub。部分操作可能需要腾讯会员权限，网络需能访问 docs.qq.com。
