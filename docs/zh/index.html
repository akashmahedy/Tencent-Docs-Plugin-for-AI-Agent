隐私说明

安装问题

找不到 Node 或 Codex？

安装 Node.js 22 或更高版本并更新 Codex。向导会尝试 macOS 桌面应用内置 CLI；也可使用 --codex 指定路径。

令牌无效或账户权限不足？

400006 通常表示令牌问题，请使用 --replace-token --skip-install 更换。400007 表示可能缺少腾讯会员权限。请按腾讯页面说明检查。

安装后没有工具？

重启 Codex、新建聊天并确认插件已启用。旧的个人安装与本插件可同时存在，请选择一个使用。
