QQ Docs、QQDocs 和腾讯文档是同一个服务吗？

是的。这里的 Tencent Docs、QQ Docs、QQDocs、腾讯文档和 docs.qq.com 指同一个腾讯在线文档服务。本项目提供 Codex 插件，并非腾讯文档官方桌面客户端。如果您要直接使用在线文档，可以打开腾讯文档官网。

Windows 与 Mac 三步安装

需要支持插件的 Codex、腾讯文档账户，以及能够访问 docs.qq.com 的网络。无需预先安装 Node.js：启动器会在需要时下载并校验运行环境。

01

下载并完整解压 ZIP

下载 v1.2.2 插件，将解压后的文件夹保存在固定位置。Windows 和 Mac 使用同一个发布包。

02

运行安装向导

Windows 双击 setup.cmd；macOS 打开 setup.command，也可以在该文件夹的终端运行下方命令。向导会准备 Node.js 并安装插件。

03

连接账户并启用插件

在腾讯令牌页面获取自己的令牌，私下粘贴到隐藏终端输入中。连接检查成功后，重启 Codex、新建聊天并启用插件。

Windows PowerShell
.\setup.cmd --lang=zh
Mac 终端 / Linux
bash setup.command --lang=zh

插件代码免费，但腾讯服务的权限和会员规则仍然适用，部分操作可能需要会员。不要把令牌粘贴到聊天或 GitHub。

让 Codex 帮您安装腾讯文档插件

复制提示词并粘贴到 Codex。它会先识别操作系统，再使用对应安装启动器；令牌由您在私密终端中输入。

Codex
请安装 https://github.com/akashmahedy/Tencent-Docs-Plugin-for-AI-Agent。按 START_HERE_FOR_CODEX.md 操作。不要假设电脑已安装 Node.js。同时支持 Windows 和 macOS。请先识别我的操作系统，再使用对应启动器：Windows PowerShell 运行 .\setup.cmd；macOS 终端运行 bash setup.command（也支持 Linux）。两个启动器都会在缺少 Node.js 或版本过旧时自动下载并校验。在 Node 就绪前不要直接运行 node setup.mjs。在交互式终端让我私下输入腾讯令牌。

如何给 Codex 添加腾讯文档插件市场？

已安装 Codex CLI 的用户可以手动添加这个 GitHub 插件市场。一般用户使用上面的安装向导即可，向导会处理插件安装。

Codex CLI
codex plugin marketplace add akashmahedy/Tencent-Docs-Plugin-for-AI-Agent
codex plugin add tencent-docs@akashmahedy-plugins

手动添加后，还需下载并解压插件，在解压目录用下面的命令配置个人令牌并检查连接。这是仓库插件市场，不代表插件已进入 OpenAI 公共插件目录。

Windows PowerShell
.\setup.cmd --skip-install --lang=zh
Mac 终端 / Linux
bash setup.command --skip-install --lang=zh

连接后，您可以这样使用 QQ Docs

下载与连接常见问题

这是腾讯文档桌面客户端的下载吗？
不是。这是给 Codex 使用的开源社区插件。若您需要腾讯文档本身，请访问 docs.qq.com。若您要让 Codex 处理腾讯文档，请下载本页插件 ZIP。
为什么安装后看不到工具？
重启 Codex，打开新聊天并启用插件。如果 Codex 不支持仓库插件市场，请先更新到支持该功能的版本。
提示 400006、认证失败或令牌失效怎么办？
先在腾讯页面获取有效令牌，再在解压目录运行启动器并加上 --replace-token --skip-install。不要将令牌发到聊天或问题反馈中。
提示 400007 或权限检查失败怎么办？
在腾讯官网检查账户、文档访问权和会员资格。插件不能绕过腾讯的权限或会员限制。
在哪里检查连接、更新或卸载？
详细安装与故障排查指南包含 --check、更新、替换令牌及卸载步骤。仍有问题可提交问题，请勿包含令牌或私人文档。
