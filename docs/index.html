Are QQ Docs, QQDocs and Tencent Docs the same service?

Yes. Tencent Docs, QQ Docs, QQDocs, 腾讯文档 and docs.qq.com refer here to the same Tencent online document service. This project is a Codex plugin, rather than the official Tencent Docs desktop app. To use online documents directly, open Tencent Docs.

Install the plugin on Windows or Mac

You need Codex with plugin support, your own Tencent Docs account and network access to docs.qq.com. Node.js does not need to be installed in advance: the launcher downloads and verifies it when needed.

01

Download and extract the ZIP

Download plugin v1.2.2, extract it completely, and keep the folder in a stable location. The same release supports Windows and Mac.

02

Run the setup wizard

On Windows, double-click setup.cmd. On macOS, open setup.command, or run the command below from that folder. The wizard prepares Node.js and installs the plugin.

03

Connect and enable the plugin

Get your token from Tencent’s token page and enter it privately at the hidden terminal prompt. After the connection check succeeds, restart Codex, start a new chat and enable the plugin.

Windows PowerShell
.\setup.cmd --lang=en
Mac Terminal / Linux
bash setup.command --lang=en

The plugin code is free. Tencent’s service permissions and membership rules still apply; some operations may require VIP access. Never paste a token into chat or GitHub.

Add the Tencent Docs Codex plugin marketplace

If you already use the Codex CLI, you can add this GitHub marketplace manually. Most users can use the setup wizard above, which handles plugin installation.

Codex CLI
codex plugin marketplace add akashmahedy/Tencent-Docs-Plugin-for-AI-Agent
codex plugin add tencent-docs@akashmahedy-plugins

After manual installation, download and extract the repository, then run the command for your operating system below to configure your token and check the connection. A repository marketplace does not mean this plugin is listed in OpenAI’s public Plugins Directory.

Windows PowerShell
.\setup.cmd --skip-install --lang=en
Mac Terminal / Linux
bash setup.command --skip-install --lang=en

Download and connection questions

Is this a Tencent Docs desktop app download?
No. This is an open-source community plugin for Codex. Visit docs.qq.com for Tencent Docs itself. Download this plugin ZIP if you want Codex to work with your Tencent documents.
Why are there no tools after setup?
Restart Codex, open a new chat and enable the plugin. If your Codex version does not support repository plugin marketplaces, update to a version that does.
How do I fix 400006 or an expired token?
Get a valid token from Tencent, then run your setup launcher from the extracted folder with --replace-token --skip-install. Keep the token out of chats and bug reports.
What does 400007 or a permission failure mean?
Check your account, document access and membership eligibility on Tencent’s own site. The plugin cannot bypass Tencent permissions or VIP restrictions.
Where are connection checks, updates and uninstall instructions?
The detailed setup and troubleshooting guide covers --check, updates, token replacement and uninstall. You can also report an issue, without tokens or private documents.

Direct connection. Local credentials.

No maintainer proxy or telemetry. macOS uses Keychain; Windows uses a per-user DPAPI-encrypted file. Linux uses a private file that this plugin does not encrypt. Codex and Tencent process your document requests. Read the privacy details.
