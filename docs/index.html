Direct connection. Local credentials.

Setup help

Node or Codex isn't found?

Install Node.js 22+ and update Codex. The wizard tries the macOS desktop app's bundled CLI; --codex lets you provide a different executable path.

Token invalid or permission denied?

400006 usually means a token problem; use --replace-token --skip-install. 400007 may mean missing Tencent VIP permissions. Check Tencent's account guidance.

No tools after installation?

Restart Codex, start a new chat and enable the plugin. An older personal installation can coexist; choose one to use.
