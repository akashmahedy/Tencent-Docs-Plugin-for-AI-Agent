# Security · 安全

Do not include credentials or private documents in public issues. For a security problem, use GitHub private vulnerability reporting if enabled on this repository. Regular installation problems can be reported with redacted error descriptions.

请勿在公开问题中附带凭据或私人文档。安全问题请使用仓库启用的 GitHub 私密漏洞报告功能；普通安装问题可提交已脱敏的错误说明。
